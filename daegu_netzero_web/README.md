# Daegu NetZero — 최종 로컬 전용 제출 후보 (v1.9.1)

대구 지역 공개 에너지 통계 및 사업장 입력/가정을 결합한 **탄소감축 사전 검토 시제품**입니다. 기존 v1.9 화면과 계산 엔진을 유지하고 **외부 LLM API 기능을 삭제**했습니다.

## 실행 (Windows CMD)

압축을 모두 풀고 `daegu_netzero_final_local` 폴더 안에서 CMD를 엽니다.

```cmd
python -m pip install -r requirements.txt
cd frontend
npm install
npm run build
cd ..
python -m uvicorn backend.api:app --host 127.0.0.1 --port 8504
```

브라우저에서 http://127.0.0.1:8504 접속합니다. 기존 8504 서버는 Ctrl+C로 종료하고 다시 실행하세요. 화면이 예전 버전이면 Ctrl+Shift+R로 새로고침합니다.

## 사용 흐름

1. 사업장 진단에서 예시 가스 사용량 120,000m³/년, 전력 550MWh/년, 목표 10%를 확인하고 **감축 시나리오 계산**합니다.
2. 공정열 분석에서 예시 설명으로 **공정 조건 추출하기**를 누릅니다. 외부 전송 없이 로컬 정규식 기반으로 명시 수치만 추출합니다.
3. 열원 70→30℃·5m³/h, 급수 20→55℃·4m³/h, 4,000h/년을 확인하고 **확인한 수치로 열수지 계산**합니다.
4. **변경된 결과 확인**에서 감축률 약 11.4%·감축량 약 54.2tCO₂/년을 확인합니다.
5. **경제성·실행계획**에서 투자비별 단순 회수기간을 확인하고 **계산 원본 ZIP 다운로드**를 누릅니다.
6. 검증·근거에서 70% 적용률 스트레스의 목표 미달 여부 및 계산 가정 한계를 확인합니다.

## 데이터와 기술 설명

- 공공 통계: 대구 북구 탄소중립 기본계획에 재수록된 KOSIS 용도별 전력 판매량(2018~2022), 도시가스 공급량(2018~2019). **원 KOSIS 항목별 직접 대조 미완료**.
- 사업장 입력: 예시 데이터 또는 이용자가 직접 입력한 사용량. 공개 지역 통계가 공장 자료를 대신하지 않습니다.
- 공정 설명 구조화: **로컬 규칙(정규표현식) 추출**. 생성형 AI나 머신러닝 예측으로 홍보하지 않습니다.
- 모델: 열·에너지수지에 기초한 조건부 회수열 상한, 가정된 기술 잠재량, 기술 도입 단계별 조합 탐색, 배출계수 시나리오 검토.
- 한계: 설비 견적·열교환기 설계·오염·압력손실·실측 운전 데이터·시간별 배출계수 미확보. 절감과 감축 효과는 실제 사업장 실증이 아닙니다.
- API: **외부 LLM 호출과 API 키 입력 UI가 없습니다.** 로컬 FastAPI는 프런트엔드 분석 기능 구동에 사용합니다.
