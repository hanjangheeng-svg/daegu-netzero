# Daegu NetZero — 제출용 작품 설명 초안

## 작품명
Daegu NetZero — 대구 사업장 탄소감축 사전 진단·실행계획 지원

## 문제 정의
중소 사업장은 에너지 비용 절감과 탄소감축 필요성을 인식하더라도 전담 인력, 공정 계측 자료, 투자 경제성 검토 여력이 부족할 수 있습니다. 이 시제품은 공개 지역 에너지 현황을 참고하면서, 개별 사업장에서 직접 입력한 가스·전력 사용량과 공정조건에 대해 조건부 감축 수단을 비교합니다.

## 주요 기능
1. 사용자 입력에 따른 기준 배출량·목표 설정
2. 공정 서술에서 열원·열수요 온도, 유량, 동시 운전시간의 **로컬 규칙 기반 추출** 및 사용자 확인
3. 열수지와 최소 접근온도 조건을 적용한 열회수량 상한 추정 및 기술조합 비교
4. 감축률, 추가 전력 사용량, 조건부 연간 비용 절감 및 단순 회수기간 계산
5. 보수·기준·상향 가정, 전력 배출계수·기술 적용률 스트레스 검증, 계산 원본 ZIP 제공

## 공공데이터 활용
대구 북구 탄소중립 기본계획에 재수록된 KOSIS 용도별 에너지 통계를 지역 상황 참고용으로 사용합니다. 개별 사업장의 에너지 사용량이나 기술 잠재율을 해당 지역 통계로부터 추정·대체하지 않습니다.

## 차별성
단순한 배출량 환산에 그치지 않고, 사용자가 확인한 공정 온도·유량·운전시간에 근거한 물리적 열회수 상한을 폐열회수 시나리오에 연결합니다. 분석 과정에는 출처·가정·계산의 한계를 구분해 표시합니다.

## 기술 및 AI 관련 정확한 표기
React 프런트엔드, FastAPI API, Python 수치 계산·조합 탐색, 정규표현식 기반 텍스트 추출을 사용했습니다. **최종 제출 버전에는 외부 LLM API 기능이 없고, 자연어 추출은 생성형 AI 모델이 아닙니다.** 공모전의 AI 활용 요건에 이 구현이 충분한지는 공고 기준으로 별도 확인이 필요하며, 미구현 AI 성능을 주장하지 않습니다.

## 한계
모든 감축량·비용 절감액·회수기간은 예시 사업장 데이터 및 미검증 기술 계수의 조건부 추정이며 실제 설비 성능을 입증하지 않습니다. 열교환기 선정, 재료·오염, 압력손실, 시간별 동시운전, 산업 현장 성능 계측, 실제 투자 견적 및 원 KOSIS 항목별 대조가 필요합니다.

## 시연 시나리오 (약 3~5분 구성 제안)
1. 대시보드에서 예시 사용량 기준 감축목표 10%, 조건부 감축률 약 10.5% 확인
2. 사업장 진단에서 가스·전력 입력 및 기술 잠재율 가정 설명
3. 공정열 분석에서 예시 문장 추출 → 7개 숫자 확인 → 승인
4. 폐수 70→30℃, 급수 20→55℃의 열교환 흐름과 연간 회수열 약 455.8MWh 확인
5. 대시보드로 돌아와 승인 후 감축률 약 11.4%·감축량 약 54.2tCO₂/년 확인
6. 경제성에서 투자비별 회수기간 비교, 검증 화면에서 적용률 70%일 때 미달 설명, 결과 ZIP 다운로드

## 제출 직전 주의
시연용 예시 수치를 실제 대구 기업의 실증성과로 설명하지 마세요. 공모전 제출 규정상 AI 활용 여부와 제출 형식 요건은 공식 공고를 보고 최종 확인해야 합니다.
