# Daegu NetZero v1.9 — 최종 UI 점검 명세

## 제품 원칙
- 기업의 실제 데이터가 아닌 예시는 명확히 표시한다.
- 결론(목표 충족 여부) → 조건(가정·자료 상태) → 근거(계산·표) 순으로 보여준다.
- 장식형 숫자와 과장된 AI 문구를 사용하지 않는다.
- 버튼은 pointer·hover·active·focus-visible·disabled 상태를 가진다.
- 모든 차트는 단위, 비교 기준, 데이터 범위, 데이터 출처·한계를 표시한다.

## 화면별 변경
1. 대시보드: 목표 달성 판정 우선, 선택 기준 간결화, 미선택 기술 명시.
2. 사업장 진단: 입력 카드의 과도한 높이 완화, 고급 가정 별도 유지.
3. 공정열 분석: 자연어 입력 → 추출값 수동 확인 → 열수지 승인 구조 유지, 물질·열 제약과 가정 구분.
4. 경제성·실행계획: 투자비 막대 제거, **회수기간(년)** 기반 비교 차트로 수정; 중복 숫자 목록 제거.
5. 공공데이터: 연도별 산업용 전력 판매량을 라인 차트로 제공, 연도·수치·증감률 및 최고/최저 명시. 연도 차이를 읽기 위한 축 절단 표시(0 시작 아님)를 노출.
6. 검증·근거: 미달 시험 조건 수를 상단에 강조하고 해당 조건·부족량을 표 아래 따로 설명.

## 최종 사용자 점검 체크리스트
- [ ] 처음 시작 시 474.5tCO₂/년, 감축 49.6tCO₂/년, 감축률 10.5% 표시
- [ ] 가정 변경 → 재계산 전 구 결과 경고 → 재계산 후 경고 해제
- [ ] 열 조건 추출 및 승인 후 감축 54.2tCO₂/년과 11.4% 표시
- [ ] 공정 보정 해제 후 기본 결과 복원
- [ ] 경제성 변경 후 연간 절감액과 회수기간에 동일한 가정 반영
- [ ] 공공데이터 2018–2022 연도, 차트 축 절단·증감률·출처 확인
- [ ] 검증 화면 미달 조건 수 및 각 부족량과 표 데이터 일치
- [ ] 모바일 너비에서도 기능 버튼, 차트, 표가 읽히고 가로 스크롤 가능
- [ ] 버튼 pointer/keyboard focus/disabled, 오류 표시, 다운로드 ZIP 확인

## 범위와 한계
- 엔진은 v1.8과 동일한 Python API 모듈; UI·시각화 표현을 수정했습니다.
- UI 그래프의 데이터는 API의 공개 통계 그대로 사용하며 새 수치를 임의로 생성하지 않습니다.
- 0이 아닌 y축을 쓰는 것은 데이터 차이를 읽기 위한 것이며 그래프에 명시합니다.
- 실제 설비 성능 또는 절감실적에 대한 검증은 포함되지 않습니다.
- ZIP 결과 파일은 원본 계산 데이터이며 별도 PDF 보고서는 포함되지 않습니다.
